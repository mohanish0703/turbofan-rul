# Results

Generated by `python -m rul.report` from 16 run records in `results/runs/`. Do not edit by hand.

- **Test**: official protocol. Each model is refit on all training engines and predicts RUL from the last window of every test engine; truth is `RUL_FDxxx.txt`, not capped.
- **Test RMSE (capped truth)**: the same predictions against the true RUL capped at the training cap, as some papers report it. Labelled extra, not the headline number. Predictions never exceed the cap, so test engines whose true RUL is above it add error to the headline number that no capped model can remove.
- **CV**: GroupKFold by engine on the training set, preprocessing refit in every fold; every window of the held-out engines against the capped target; mean +/- std over folds.
- **Selected**: lowest CV RMSE per dataset. Test results play no part in the choice.
- **Models**: `naive` predicts the mean training target; the others regress on per-sensor window statistics (last, mean, std, slope) plus the cycle number. Hyperparameters are hand-set defaults, not tuned.
